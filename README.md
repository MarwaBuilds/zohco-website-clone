# Zohco — Eco-Friendly Website Clone 🌱

A fully responsive **Zohco website clone** built as a web development bootcamp project.

I recreated the original design from scratch using **HTML, CSS, and basic JavaScript**, focusing on responsive layouts, modern UI styling, navigation, interactive elements, and maintaining the visual structure of the original website across different screen sizes.

### 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

### ✨ Features

* Responsive design for desktop, tablet, and mobile
* Modern eco-friendly landing page
* Responsive navigation menu
* Services and values sections
* Statistics and testimonials
* Blog section
* Newsletter section
* Interactive UI elements

### 🚀 Live Demo

https://zohco-a-bootcamp-project.vercel.app/

### 🎓 About the Project

This project was created as part of my **Web Development Bootcamp at NETLINKS** to practice turning an existing design into a functional, responsive website using fundamental frontend technologies.

> **Educational project:** This is a frontend clone created for learning purposes and is not affiliated with the original Zohco website or its creators.
